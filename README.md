# uriesmooth-p2pv26
Uriesmooth P2P v26 is the core real-time communication framework within the Uriesmooth application suite. Built as a serverless, zero-trust media engine, it uses WebRTC, WebGPU hardware acceleration, and WASI WebAssembly components to deliver sub-15ms peer-to-peer audio, video, and data synchronization across web, desktop, and mobile environments.
